# KABU (KKB)

Community-driven meme coin on Solana. This folder is a static site ready for GitHub Pages.

## Publish on GitHub Pages

1. Create a public GitHub repository.
2. Upload every file in this folder. Keep this structure:

```
index.html
styles.css
script.js
assets/kabu-logo.png
README.md
```

3. Open **Settings → Pages**.
4. Set Source to branch `main` and folder `/ (root)`.
5. After a minute the site will be live at:

`https://YOUR_USERNAME.github.io/YOUR_REPO/`
