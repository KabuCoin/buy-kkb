# KABU (KKB) Website — v2

A polished static GitHub Pages landing page for KABU on Solana.

Upload the files in this folder to the repository root:
- index.html
- style.css
- app.js
- assets/kabu-logo.png

Then enable GitHub Pages:
Settings → Pages → Deploy from a branch → main → /(root)
